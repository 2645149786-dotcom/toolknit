> **Every tool runs 100% client-side.** Your files never leave your device. No server uploads, no accounts, no tracking cookies, no data collection. Open DevTools → Network tab to verify it yourself.

## ✨ Highlights

- 🔒 **Privacy by Design** — All processing happens in your browser via JavaScript, Canvas, WebAssembly, and Web Audio APIs
- 🆓 **Completely Free** — No sign-up, no watermarks, no file size limits, no premium tier
- ⚡ **Instant & Offline-capable** — PWA with Service Worker; works without internet after first visit
- 🌍 **Multilingual** — English + 中文 (Chinese) with automatic locale detection
- 📱 **Responsive** — Works on desktop, tablet, and mobile
- 🎯 **86 Tools** — PDF, Image, Video, Audio, Text, Calculators, Time, Creative, AI, and more

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| **Vanilla JavaScript** | Core tool logic — no React, no Vue, no framework overhead |
| **Canvas 2D API** | Image manipulation, drawing, pixel-level processing |
| **WebAssembly** | Video/audio processing (ffmpeg.wasm), AI inference (ONNX Runtime) |
| **PDF.js / jsPDF** | PDF rendering and generation |
| **Web Audio API** | Audio processing, synthesis, and format conversion |
| **Web MIDI API** | MIDI device connectivity for music tools |
| **Service Worker** | Offline support and caching (PWA) |
| **Tailwind CSS** | Utility-first styling |
| **Web Crypto API** | Hash generation and secure random numbers |

## 🔒 Privacy

| Claim | How to verify |
|---|---|
| No file uploads | Open DevTools → Network tab; zero POST requests during tool use |
| No user accounts | No login form, no database, no user data stored |
| No tracking cookies | Check Application → Cookies; only essential session cookie |
| No third-party analytics | Self-hosted tracker.js; no Google Analytics on tool pages |
| Client-side only | All source code runs in the browser; inspect any tool's JS |
