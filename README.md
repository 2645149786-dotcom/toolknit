## Why ToolKnit Exists

Most online tools require signups, upload your data to servers, or are wrapped in ads. ToolKnit is different:

- **No backend** 鈥?everything runs in the browser via Canvas, Web Audio, File API
- **No signup** 鈥?just open a tool and use it
- **No uploads** 鈥?files stay on your device
- **No tracking** 鈥?minimal analytics, no third-party marketing scripts
- **Bilingual** 鈥?English + Chinese, more languages planned
