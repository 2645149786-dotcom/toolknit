## Why ToolKnit Exists

Most online tools require signups, upload your data to servers, or are wrapped in ads. ToolKnit is different:

- **No backend** &mdash; everything runs in the browser via Canvas, Web Audio, and the File API
- **No signup** &mdash; just open a tool and use it
- **No uploads** &mdash; files stay on your device
- **No tracking** &mdash; minimal analytics, no third-party marketing scripts
- **Bilingual** &mdash; English + Chinese, with more languages planned
